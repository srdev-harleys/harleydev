User Guide — Harleys Odoo 19 Enterprise

Rista Sales Reports

Every order rung up in-store or through Zomato/Swiggy passes through Rista, our POS system. This guide covers where to see that data inside Odoo, what each report is for, and the two mapping screens that connect Rista's own branch/item codes to our warehouses and products.

Audience Anyone viewing Rista sales reports, or maintaining Outlet/Item Mapping Reading time ~6 minutes

1. What this is, and where to find it

Rista is the point-of-sale system Harley's stores actually use to ring up orders — not Odoo. This integration brings that sales data into Odoo automatically, every day, purely so it can be viewed, filtered and exported alongside everything else here. It's read-only: nothing done in these screens changes anything in Rista.

2. The five reports, and which one to use

ReportShowsUse it when...
POS OrdersOne row per order/invoiceYou want order-level totals — how many orders, total sales, by branch or day
POS Order LinesOne row per item soldYou want a lean, focused view of what sold — quantity, price, discount, nothing else
Sales DetailOne row per item sold, every available columnYou need a specific field not shown on POS Order Lines — this has everything, with columns you don't need hidden behind the column-picker (top-right of the list)
Sold Out HistoryItems that went out of stock and came backChecking how often, and for how long, a specific item was unavailable
Outlet StatusCurrent status per branch and delivery channelA live snapshot — not a history — of whether a branch is currently open on Zomato, Swiggy, etc.

Every report can be grouped, filtered and pivoted the same way as any other Odoo list — by branch, by day, by channel (Zomato/Swiggy/in-store), or by brand.

3. Outlet Mapping and Item Mapping

Rista knows branches and items by its own codes. These two screens (under Configuration) connect those codes to the actual Odoo warehouse or product, so reports elsewhere in Odoo can use them too.

1Open Outlet Mapping

Lists every Rista branch, and which Odoo warehouse it's linked to.

2Use Auto-Map first

Click Auto-Map at the top of the list — it matches any unmapped branch to a warehouse with an exact matching code or name, in one click. Anything it can't match with confidence is left alone for you to check.

3Fill in the rest by hand, or by Excel

For anything Auto-Map couldn't resolve, either pick the warehouse directly on that row, or use Odoo's own Excel export/import: export the list, fill in the Warehouse Code column, re-import.

4Item Mapping works the same way

Same idea, connecting Rista's item codes (SKUs) to Odoo products — its own Auto-Map button, and the same manual/Excel options.

Seeing two items with the exact same name? That's expected for cakes that come in more than one size — Rista sends the same name for every size of a cake, so "Signature Belgium Chocolate Medovik Cake" showing up twice usually means one row is the 600 Gm size and the other is 1 Kg, not a duplicate. If you're unsure which is which, check the item's SKU code against Rista directly before mapping it.

4. Why some cells are blank

You may notice some columns are blank for certain orders — this is intentional, not missing data. Rista simply doesn't send every field for every order. For example:

  • Device Label, Sale By User, Person Count — only sent for orders rung up on an in-store terminal. A Zomato/Swiggy delivery order rung in automatically by Rista's own system won't have these, and that's correct.
  • Voided Time, Processed Attempt Time — only filled in if that specific thing actually happened to the order. Most orders never get voided, so this stays blank for them.

Where a number is shown as blank rather than 0, that's also deliberate — it means Rista genuinely didn't send a value for that field on that particular order, as opposed to sending an actual 0. Both are shown differently on purpose, so a blank never gets mistaken for a real zero.

5. Who can see what

Viewing the five reports above only requires the Rista Reports Viewer permission — a manager can grant this on its own, without also handing out access to the technical Connect/integration settings. Outlet Mapping, Item Mapping and the Configuration menu require the broader Connect Manager permission, since those affect how data is captured.

6. Common questions

Can I edit an order or item from these screens? No — everything here is read-only, pulled from Rista automatically. To fix something about an actual order, it needs to be corrected in Rista itself; the correction will appear here on the next sync.
How current is this data? Synced automatically once a day. It's not a live, real-time feed — Outlet Status in particular is a snapshot as of the last sync, not the current second.
An item or branch is unmapped — does that break the report? No, the order/item still shows up with all its own data. Only the link to a specific Odoo warehouse or product is missing until it's mapped, which mainly matters if you're trying to cross-reference against inventory or product-level reports elsewhere in Odoo.
Why do POS Order Lines and Sales Detail look similar? They show the same underlying items, just with a different number of columns — POS Order Lines is deliberately kept to the 10 essentials, Sales Detail has everything available in case you need a less common field.
