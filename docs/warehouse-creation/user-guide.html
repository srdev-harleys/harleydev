1. Purpose

This SOP explains the standard procedure for creating a new outlet warehouse in Odoo 19 by duplicating a similar existing outlet and updating the required configuration.

2. Scope

This procedure applies when a new outlet/warehouse needs to be created in Odoo 19 using an existing outlet and warehouse as a template.

3. Prerequisites

Before starting the warehouse creation process:

  • Identify an existing outlet in the same company that is similar to the new outlet.
  • Identify the corresponding warehouse of that outlet to use as the duplication template.
  • Keep the new outlet's details available:
    • Outlet Name
    • Address
    • Email
    • Phone Number
    • Short Name

4. Procedure

Complete the following steps in order. Each checkpoint confirms that the configuration is ready for the next step.

Step 1 – Create the Outlet Contact

  1. Go to Contacts.
  2. Search for an existing outlet that is similar to the new outlet and belongs to the same company.
  3. Open the existing outlet/contact.
  4. Use the Duplicate option to create a copy.
  5. Update the required outlet details in the duplicated contact:
    • Name
    • Address
    • Email
    • Phone Number
    • Other outlet-specific information, if applicable
  6. Save the contact.
Checkpoint Verify that the new outlet contact contains the correct name, address, email, phone number, and company.

Step 2 – Create the Warehouse

  1. Go to Inventory → Configuration → Warehouses.
  2. Find the warehouse corresponding to the similar existing outlet identified earlier.
  3. Open the warehouse.
  4. Use the Duplicate option to create a copy.
  5. Open the newly duplicated warehouse.
  6. Uncheck Manufacture to Resupply.
  7. Update the warehouse details:
    • Warehouse Name: Enter the new outlet warehouse name.
    • Short Name: Enter the new outlet short name.
    • Address: Select the outlet contact created in Step 1.
  8. Save the warehouse.
Checkpoint Verify that the warehouse name, short name, address, and Manufacture to Resupply setting are correct.

Step 3 – Verify the Internal Location

  1. Go to Inventory → Configuration → Locations.
  2. Search for the internal location associated with the newly created warehouse.
  3. Verify that the internal location has been created automatically.
  4. Open the internal location.
  5. Verify the location configuration.
  6. Uncheck Replenishment.
  7. Save the location.
Checkpoint Confirm that the new warehouse has its required internal location and that Replenishment is disabled.

Step 4 – Configure Operation Types

4.1 Verify POS Orders and Internal Transfers

  1. Go to Inventory → Configuration → Operation Types.
  2. Search for the operation types associated with the newly created warehouse.
  3. Verify that the following operation types are available:
    • POS Orders
    • Internal Transfers

4.2 Create the Transit Operation Type

  1. In Operation Types, find the Transit → Short Name / Stock operation type of a similar existing outlet.
  2. Open the operation type.
  3. Use the Duplicate option.
  4. Open the duplicated operation type.
  5. Update the following fields:
    • Sequence Prefix: Change it to the new outlet's short name.
    • Warehouse: Select the newly created warehouse.
    • Destination Location: Select the correct destination location for the new outlet.
  6. Verify that the source and destination locations are configured correctly.
  7. Save the operation type.
Checkpoint Verify that the operation type is linked to the correct warehouse, sequence prefix, and destination location.

Before considering the warehouse creation complete, verify the following:

6. Completion Criteria

The warehouse creation is considered complete only after:

  • The outlet contact has been created and verified.
  • The new warehouse has been created and configured.
  • The internal location has been verified and configured.
  • POS Orders and Internal Transfers operation types have been verified.
  • The required Transit operation type has been duplicated and correctly configured.
  • All final verification checklist items have been completed.
